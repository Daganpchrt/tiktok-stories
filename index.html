01 Terms of Service

What this is

Daily Story is a personal automation script. It generates narrated vertical videos from text, then publishes them to TikTok accounts that its owner controls, using TikTok's Content Posting API. It has no public website, no user registration, and no audience beyond its single operator.

Who can use it

Only the owner. The app is not distributed, and TikTok accounts are connected to it one at a time, deliberately, by the account holder authorizing access through TikTok's own consent screen.

Acceptable use

  • The tool is used only to publish content the owner has produced and reviewed.
  • All publishing goes through TikTok's official Content Posting API and remains subject to TikTok's own Terms of Service and Content Sharing Guidelines, in addition to this document.
  • The tool does not scrape TikTok, impersonate other accounts, or act on any account without that account's own OAuth authorization.

No warranty

Provided as-is, with no uptime or support commitment — it is a personal utility, run locally, maintained on its owner's own schedule.

02 Privacy Policy

This policy covers the TikTok accounts connected to Daily Story. There is no other audience: the tool collects nothing from anyone browsing this page, and nothing from TikTok viewers of the posted videos.

STORED LOCALLY

OAuth access & refresh tokens, one file per connected TikTok account, on the owner's own machine. Never uploaded anywhere.

SENT TO TIKTOK

Only what the API requires to publish a video: the video file, its caption, and the requested privacy setting.

NEVER COLLECTED

No analytics, no tracking pixels, no viewer or follower data, nothing sold or shared with a third party.

Data TikTok returns to the app

DataPurpose
open_idIdentifies which connected account a token belongs to.
access / refresh tokenLets the tool publish on behalf of the account that granted it, until revoked.
Creator info (privacy options, posting limits)Read immediately before each post, as TikTok's API requires, to submit a valid request.

Retention & deletion

Tokens are kept until the account owner disconnects the app (from TikTok's own account settings) or deletes the local token file. Deleting the file or revoking access in TikTok immediately stops the tool from posting.
